## Controlled Disposition

**REJECTED — NOT APPROVED AS CURRENT PROJECT DESIGN BASIS / PUBLICATION**

AST-000053 / A-012 is rejected as the current controlling entire-resort ground-floor-plan design basis.

The rejection applies to the consolidated ground-floor-plan package and its associated master-plan representation.

The drawing shall not be used as the current controlling basis for:

- Entire-resort ground-floor planning
- Consolidated facility positioning
- Cottage cluster planning
- Master-plan-derived architectural publication
- Current cottage accommodation representation
- Consolidated area scheduling
- Current project architectural design basis

The rejection also does not independently invalidate individual facilities where those facilities have separate controlled design records.

## Rejection Basis

AST-000053 is rejected because:

1. It explicitly derives its arrangement from the **locked master development plan**.
2. The referenced master-plan direction represented by AST-000049 / A-010 has already been rejected.
3. The entire-resort key plan reproduces that rejected development arrangement.
4. The cottage component is represented generically as **C-01 to C-08 Eco Luxury Cottages (Typical)**.
5. The source represents **8 × 275 sq.ft.** generic cottages rather than the established **2 Premium + 6 2-BHK Family** accommodation mix.
6. The source orientation representation differs from the controlled project orientation convention.

These conditions prevent AST-000053 from being accepted as the current consolidated project design basis.
