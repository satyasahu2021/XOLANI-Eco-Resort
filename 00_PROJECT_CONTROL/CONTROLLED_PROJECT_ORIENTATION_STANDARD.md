# XOLANI ECO RESORT & AQUA RETREAT
# CONTROLLED PROJECT ORIENTATION STANDARD

Status: APPROVED / LOCKED / MANDATORY
Effective: 20 AUG 2026
Scope: All controlled drawings, drawing analysis reports (DAR), DDIF/AMI
records, corrected drawing artifacts, and subsequent drawing inspections.

## Established Controlled Project Orientation

The project orientation is permanently established as:

- North: DOWN (N)
- South: UP (S)
- East: LEFT (E)
- West: RIGHT (W)

Compact notation:

N ↓ / S ↑ / E ← / W →

## Mandatory Application

This orientation shall be used as the controlled project standard for
future drawing inspection and analysis.

For every subsequent AST asset:

1. Inspect the actual drawing compass/orientation.
2. Compare it against this controlled project orientation.
3. Record any discrepancy in the applicable DAR.
4. If a correction is approved, correct only the required orientation
   representation unless the controlled drawing instruction explicitly
   authorizes other changes.
5. Re-open and visually re-inspect the generated/corrected drawing.
6. Preserve the original drawing filename.
7. Do not infer approval from neighboring drawings; verify each actual
   drawing.
8. Do not silently rotate or mirror substantive drawing geometry.

## Controlled Precedent

DAR-029 records the same orientation as the approved XOLANI project
orientation and confirms the correction/verification process.

## Governance

This document is a controlled project rule. It is not a per-drawing
assumption and shall not be overridden by the orientation printed on an
individual source drawing.

Any proposed change to this project orientation requires an explicit
controlled project decision before it may be applied to subsequent
drawings.
