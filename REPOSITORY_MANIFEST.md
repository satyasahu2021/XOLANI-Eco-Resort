# REPOSITORY_MANIFEST.md

## Purpose

This document defines the purpose of each top-level repository area.

| Folder | Purpose |
|---------|---------|
| 00_PROJECT_CONTROL | Governance, audit, registers, certification |
| 01_DOCUMENTS | Source project documentation |
| 02_DRAWINGS | Engineering drawings and layouts |
| 03_FINANCE | Financial models, BOQs and projections |
| 04_REFERENCE | Legal and supporting references |
| 05_DPR | DPR drafts and final versions |
| 06_SUBMISSIONS | Lender and authority submissions |
| 99_ARCHIVE | Historical and superseded material |

## Audit Outputs

Repository Audit outputs shall be stored under:

00_PROJECT_CONTROL/
- 01_AUDIT
- 02_REGISTERS
- 03_REPORTS
- 04_DASHBOARD
- 05_CHANGE_CONTROL
- 06_CERTIFICATION
